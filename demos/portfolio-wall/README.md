# 悬浮创作展墙 Demo

根据用户提供的 Coze 页面开发提示词制作，技术栈为 React + Tailwind CSS + Vite。

## 打开

直接双击本目录的 `portfolio-wall-demo.html`。此文件已内嵌脚本、样式和原创 SVG / DOM 插画，无需服务器和网络资源。

开发预览：在本目录运行 `npm.cmd install`，然后运行 `npm.cmd run dev`，访问 http://127.0.0.1:5180/。

重新构建与生成单文件：`npm.cmd run build`。

## 已实现

- 深炭灰展墙、三张悬浮装饰卡、六个不同项目封面、桌面双列错落与平板/手机单列布局。
- 项目封面倾斜和图层浮起，文字保持平面；项目详情从卡片位置展开与收回，支持 Escape、遮罩关闭及背景滚动锁定。
- 个人资料卡的轻微倾斜与反光、联系方式弹窗、演示邮箱复制、未公开链接提示。
- 10 条预设问答、手动输入兜底、最小化/关闭与会话内历史保留，手机聊天全屏。
- 可见的暂停入口、系统减少动态支持、页面隐藏时停止持续动画。

人物、教育/工作经历、成果数字、联系方式、插画与项目均为演示数据。邮箱使用 example.com 保留域名；微信为明确标注的不可扫码展示图形；未连接真实个人主页、项目站点、AI 或后端。

## 与原提示词的处理差异

- “取消卡片最大倾斜角度限制为10度”语义不清，按“倾斜不超过10度”处理，项目封面上限7度；文字不继承倾斜。
- 暂停按钮可见；为391–767px手机和窄屏补齐连续布局，避免固定600px卡片溢出。
- 只有桌面重点作品比其余卡片宽20%；平板和手机统一宽度。
- 动效按以下来源行为重新实现，未直接集成其完整源码：
  - 3D Card：22fa77bef9456d26，https://ui.aceternity.com/components/3d-card-effect
  - Profile Card：356c34ccaf53edf1，https://reactbits.dev/components/profile-card

## 验证

开发预览启动后，在本目录运行 `npm.cmd run verify`。脚本使用工作区已有 Playwright；独立移出工作区时需另行安装 Playwright 并准备 Chromium。

浏览器检查涵盖桌面、平板、手机、六个详情、聊天、复制邮箱、暂停和减少动态；截图及结果保存在 `artifacts/`。
