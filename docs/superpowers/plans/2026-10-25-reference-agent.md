# 按需检索参考库实施计划

**Goal:** DeepSeek通过真实工具搜索350条参考并读取需要的完整知识，再组合专业页面提示词。

**Architecture:** 保留现有案例与知识文件，新增只读全库搜索/详情工具及DeepSeek多轮工具调用模块。DeepSeek初始请求只含需求、设计规则、库规模与用户指定资料，不注入全库详情；模型自主搜索、读详情、继续查找后输出。最终引用只允许来自本次实际读取或用户确认的可用案例，继续保留真实来源、作用层、停止请求和近期组合重选保护。

**Scope:** 直接DeepSeek提示词流程。Coze和其他兼容服务保持现有流程；不新增数据库、上传或页面代码生成能力。
