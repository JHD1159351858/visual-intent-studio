# Coze 知识库导入说明

这里是从本项目当前参考库生成的首版文字知识库：350 张案例卡片，覆盖结构 66 条、样式 90 条、交互效果 194 条；另外包括设计组合与应用边界规则。待整理的三条案例未加入。

本地文件已生成；本轮更新不会自动上传、绑定或发布。云端当前文档与绑定状态应在Coze中核对，不能用本地导出数量推定云端已更新。

## 基础案例与规范

- [01-设计与使用规则.txt](01-设计与使用规则.txt)：匹配资格、组合规则、作用层、局部修改和输出一致性。
- [02-页面结构案例.txt](02-页面结构案例.txt)：66 张结构案例卡片。
- [03-视觉样式案例.txt](03-视觉样式案例.txt)：90 张样式案例卡片。
- [04-交互动效案例.txt](04-交互动效案例.txt)：194 张交互案例卡片。

每张卡片保存真实 ID、中英文名称、口语别名、效果说明、触发方式、适用位置、标签、来源地址、实现参考、预览来源性质、验证边界及用户备注。来源记录与设计建议分开；28 条产品案例没有源码地址，资料会明确说明。

## 在已登录的 Coze 中导入

1. 在该智能体所在工作空间创建文本知识库，建议命名“见意设计参考库 v1”。需要当前账号具备在该空间创建资源的权限。
2. 通过本地文件导入上传上面四个TXT，以及下文的05、06和07；已有同名文档应替换，避免重复召回旧规则。不要上传manifest.json或本说明文件。
3. 01–06建议按自定义分隔符 `---CASE---` 分段，保留URL和单张卡片的ID、行为与来源；案例片段可先用2000 token上限并检查预览。07是完整输出样例，单独检查其导入与分段，不套用案例卡片的分段长度。
4. 等待文件全部处理完成，核对02–04案例文件中的350个不同ID；07内的示例引用不计入新增案例。
5. 在智能体配置中绑定该知识库，设置混合搜索。可启用自动调用；如果采用按需调用，现有提示词已要求在匹配、比较、组合与页面规划时检索设计知识。
6. 保存配置并重新发布到 API。只上传工作空间资源而未绑定、或者只修改草稿未发布，都不能让当前网页调用到新知识库。

推荐模式仍以每轮 `availableCatalog` 为候选白名单；知识库补充理解，不允许从召回中补出本轮不存在的案例 ID。可以在 Coze 调试中询问：“流动渐变光晕的案例 ID 是什么？只用于玻璃边缘时应该保留哪些属性？”检查召回、案例 ID 与边框/表面区分。

## 视频与视觉证据

这里导入的是文字资料，**视频未上传到 Coze**。`/media/` 路径仅用于本地网页播放，云端无法直接读取。预览已验证不等于模型已经看过画面。后续需要视觉判断时，应实际提供可访问的关键帧或截图。

## 更新本地导出

在项目目录运行：

```powershell
npx.cmd tsx scripts/export-coze-knowledge.ts
```

脚本重新读取本地目录及用户备注，写入01–04和manifest.json。云端替换对应文档后，再核对处理状态与智能体绑定。此命令不会修改Coze云端，也不覆盖手工维护的07样例。

## 补充整页与组件资料

`npm.cmd run export:design-knowledge` 单独生成 [05-整页设计范例.txt](05-整页设计范例.txt) 与 [06-高频组件实现.txt](06-高频组件实现.txt)，分别包含7套整页的用途、参数、区域与搭配规则，以及20项原生组件的作用层、参数、兼容性和适配边界。使用独立的design-library-manifest.json核对数量，不覆盖01–04或原manifest。

可以将这两个 TXT 追加到已有文本知识库，按 `---CASE---` 分段，保持每套配方或组件资料在同一段。云端看不到文件中提到的本地 HTML、PNG 路径；运行时由本项目后端将匹配的完整页面和组件代码直接注入生成请求。导出与本地注入均不代表文件已上传到 Coze。

## 完整提示词输出样例

[07-页面开发提示词输出样例.txt](07-页面开发提示词输出样例.txt)是用户认可的强动效页面提示词，包含完整输入与合格输出。它提供从整页构图到逐效果机制、参数、功能和验收的写法，不是新增组件清单。此文件手工维护，不属于两个自动导出manifest，单独导入并检查完整度。

在智能体中同时替换[系统提示词](../coze-agent-prompt.md)，按[提示词模式说明](../Coze-提示词模式说明.md)测试。只更新知识文件不足以清除旧的HTML代码交付规则；知识样例也不能保证每次被完整召回，所以核心成品结构与精简样例已写入系统提示词。后续模型只输出页面开发提示词，代码实现交给独立开发模型。

## API 资料

自动导入需要知识库创建和文档上传权限；自动绑定与发布还需要智能体编辑和发布权限。可参考扣子官方的[创建知识库](https://docs.coze.cn/developer_guides_create_dataset)、[创建知识库文件](https://docs.coze.cn/developer_guides_create_knowledge_files)、[更新智能体](https://docs.coze.cn/developer_guides_update_bot)与[发布智能体](https://docs.coze.cn/developer_guides_publish_bot)。不要把管理令牌放入前端或导入文件。
