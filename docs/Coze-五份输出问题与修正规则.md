# 五份Coze页面提示词审查

审查日期：2026-10-16。依据为用户提供的健身、音乐、作品集、旅行与课程查询五份提示词，以及本地353条记录中的350条可用参考。本报告分析输出文本，没有将这些页面重新实现，也不将提示词审查当作视觉验收。

## 已确认的问题

五份全部写死“独立HTML、CSS与原生JavaScript内嵌、单文件、无外部资源依赖”。这不是用户对所有页面的要求，来源是之前强动效样例的预览交付方式被当成通用规范。这会限制组件复用、依赖安装、素材与工程组织。用户现已明确要求根据需求选择技术栈；不将默认值简单改成所有页面一律React。

五份共有16处带案例ID的引用，其中6个ID不在本地目录：animated-progress-bar、button-press-effect、page-flip-effect、animated-path-draw、3d-card-flip、floating-card-hover。其余10处ID和来源地址匹配本地记录。未知ID不应被计为已调用参考库；其中3d-card-flip还使用了真实3d-card-effect地址，但该地址对应本地22fa77bef9456d26。真实地址也不能支持任意行为声明。证据整理在artifacts/source-link-audit-20261015/pasted-prompt-review.json；没有对这六个字符串都作逐页404判断。

## 逐份修改

### 铁序：健身计划

两条带来源的进度条和按钮效果引用都不是本地真实案例。普通进度填充和按压反馈可以直接列为自主设计，不强行赋予案例ID；若要采用库内效果，应检索行为适配的真实记录，不仅找名称相似条目。

问卷、周计划、选中训练日和完成状态适合按组件与状态组织，提示词应说明所选方案与理由。演示动作和预设计划可以成立，但未提供专业规则时，不凭空输出“为了达到某目标每周至少X天”的权威判断。安静的训练内容配进度反馈符合原测试需求，不必强塞大面积背景动画。

### 音绪：音乐推荐

背景渐变动画的ID与地址是真实记录，其余基础交互可作为自主组合。但“无真实音乐文件、音频占位”与“播放、音量、切歌功能正常”的验收矛盾：有可用且合适的音频素材才验收真实播放；否则明确为播放器状态演示，不承诺出声或有效音量控制。固定节奏波形不是对真实声音的分析结果。

不得写“所有动效降低到30fps”。仅Canvas或自定义JavaScript绘制循环可设目标帧率；CSS通过减少运动元素、模糊与叠层面积、离屏暂停等控制成本。无实际异步任务时不为了显示加载强制等待一秒。

### 悬浮空间：作品集

三条带ID的引用均能对应本地案例；问题集中在同一张卡片叠加持续浮动、指针倾斜、滚动视差与展开。应明确分层及属性所有权，避免多个动画写同一个transform；展开时暂停原卡片的倾斜。不能只列一串transform术语而不说明如何共存。

减少动态时仍保留“悬停放大”，与关闭所有非必要位移和缩放的承诺不一致；触屏也不应依赖hover。使用静态层次、即时边框或颜色保留反馈。个人信息和项目内容可用明确演示材料，避免只有姓名与空封面占位。

### 行记：旅行手册

五处引用中四个ID不在本地库。3d-card-effect记录的是悬停分层透视，不能直接声称它是180度翻转案例。手册展开、地图路径绘制和卡片反馈可以自主设计，但必须说明实际能达到的形态，不用猜测的组件地址背书。

图片导出是新增功能，地图缩放更是只在验收末尾出现；它们不属于原测试明确要求。默认保留行程生成、按天查看、详情和替换；额外能力列为可选建议。如用户采用，再补齐入口、导出范围或缩放操作、状态、依赖及验收。

### 深海蓝：课程查询

五处带ID引用均匹配本地记录，已有打开可见的持续主视觉；不因未凑齐六项就判错。书册默认浮动和鼠标倾斜需分属嵌套元素，磁吸按钮应由固定外层承载点击区域，移动视觉放在内层。不能一边变换按钮本体，一边口头声称命中区域不动。

删除单HTML与全部内嵌的固定交付要求，说明课程范围、问答、引用弹窗、历史与运动控制的状态组织。暂停描述中提到Canvas，但本版没定义Canvas效果时，应按实际采用的绘制方式处理，不复制无对应对象的验收词。对相关知识推荐等额外功能注明是否为本次建议。

## 新版通用规则

1. 技术选型：用户要求优先；已有工程沿用原栈；新项目按复杂度选型并解释。说明工程组织和运行方式，只有明确受限交付才要求单HTML。
2. 引用真实性：名称、ID、sourceUrl与implementationUrl来自同一条真实资料；未知来源标为自主设计，不拼链接，不给普通控件编ID。
3. 行为真实性：区分原效果、用途改造、自主组合；链接真实不代表其支持任何视觉描述。
4. 动效共存：为浮动、倾斜、视差、展开等分配独立元素或明确统一合成方式；稳定输入和点击区域。
5. 素材闭环：音频、图像、地图和服务是否真实可用，与功能和验收保持一致，不能用“演示”掩盖无功能。
6. 状态闭环：正常、触屏、用户暂停、减少动态的处理一致；验收只验证已定义功能，不在最后新增需求。
7. 性能可执行：Canvas与自定义渲染才规定帧率，CSS不笼统承诺30fps；不承诺未经测试的绝对流畅。
8. 保留差异：按业务和最新偏好决定动效强度，不把健身、音乐、作品集、旅行、课程全部压成同一份模板。1440/390是验收尺寸，不是所有页面都必须使用的换栏断点。
