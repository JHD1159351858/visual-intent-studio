# 用户认可案例的设计原则

这份记录用于维护生成规则，不能视为已经实测这些页面或验收其全部来源。原始案例由用户提供；运行时只发送提炼后的简短原则，不逐次附带四份长提示词，也不把其中的ID、配色、技术栈或效果名单当默认模板。

| 案例 | 值得保留的组织方式 | 不应机械复制 |
| --- | --- | --- |
| 环流·数字地球实验室 | 轨道观测与野外纸本是统一概念；大地球、云层、坐标、纸质档案和页签都有明确分工；关键轮廓、纹理、字体和回退写到可执行 | 单主路由和档案页签是一种有效应用结构，并不要求所有工具拆路由；五个来源也不意味着来源越少越美 |
| 摩尔实验室 | 旋涡、分子卡、章节几何和分步讲解共同表达化学结构；浅色蓝紫、公式字体、上传演示与练习状态相互协调 | 长页与圆润卡片并非天然不好；不把旋涡、网格或同套配色变成所有学科默认 |
| 护考脉冲 | 主视觉的脉冲语言延伸到模式、进度和反馈；题干解析稳定，复杂状态和手机答题卡有具体规则 | 多种强动效可以并存，但不凑固定数量；演示题目不作为医学或官方题库依据 |
| 夜航音乐专辑 | 唱片、空间立方体、播放器与选曲/收藏围绕专辑揭幕组织；曲目列表和播放状态共用明确数据 | 长页和玻璃可在此主题成立，不推广到所有工具；没有音频时只作明确的播放状态演示 |

共同标准是：先写出一条清楚的用户路径与视觉主张，再确定形态、材质、层级、内容状态和素材质量，最后让每项动效服务同一主题。不能将“是否多页”“深色或浅色”“引用数量”“是否圆角卡片”中的任一项当成美观判据。

应用结构应区分主路由、功能视图与锚点：同一网址也能通过页签或抽屉形成完整任务空间；多网址也可能只是分开的宣传区块。只有确需分享、前进后退或刷新定位的任务才引入相应路由要求。

实现说明要明确角色与取舍。例如来源组件的触发、算法或作用层发生变化，应标记用途改造；主要主体需要合适轮廓、纹理、字体、模型或图表，不能为图省事擅自禁用素材而退成粗糙占位。素材地址与来源事实须有依据，不把样例ID或实现方式直接当成本轮已读取内容。

样例中的局限也不照搬：不固定React/Vite版本、单文件形式、禁止安装来源组件、离线字体要求、虚构处理等待或重复来源列表；用户明确要求、工程条件和本轮实际资料优先。仍保留正文稳定、触屏可用、暂停/减少动态和真实验收边界。

## TERRA LAB 实图修正记录

2026-10-26 对照实际运行的 5173 页面与用户认可的 5195「环流」。失败样例同时要求固定右侧工作台、最高 620px 的画布、26–34px 标题、简化大陆多边形及全屏云海，造成小主体、通高空栏、粗轮廓与背景灰雾。这些是提示词自身的具体取舍问题，不能归因于动效不够或下游模型。

实图修正采用大地球、按需纸本档案、本地衬线字、Natural Earth 真实轮廓与贴球云层，保留原有八个地区、问答、练习及错题。只提炼两项通用规则：按相机投影后的可见主体核算占比；按用户路径决定面板常驻或按需。地球、深绿色、纸本、衬线和抽屉不是所有页面的默认模板。

本轮验证的是手工修正后的运行页面；生成规则已更新，但尚未重新调用 DeepSeek 生成并实现一个新页面，不能据此声称模型输出的美观程度已稳定提升。实测材料位于 artifacts/geography-visual-diagnosis/。
